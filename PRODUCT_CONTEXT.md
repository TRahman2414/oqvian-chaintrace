# Product Context

OQVIAN CHAINTRACE demonstrates a focused investigation workflow for security teams who receive disconnected alerts from identity, cloud mail, administrative, and file-access sources. It groups events only when explicit deterministic conditions support the relationship, then exposes the evidence and reasoning so an analyst can verify the story.

## Audience

The showcase is intended for SOC teams, managed security providers, SaaS operations teams, corporate IT, and security consultants evaluating a future custom implementation.

## Fictional environment

Use the fictional Meridian Digital Services organization and clearly synthetic identities, assets, IPs, and domains reserved for documentation. No real user or customer records belong in fixtures.

## What a viewer should learn

1. A burst of failures can be a signal but is not proof of compromise.
2. Explicitly unfamiliar successful sign-in context can raise priority.
3. Privilege, forwarding, and bulk-download activity can add distinct stages when the target identity and time windows match.
4. The incident is a hypothesis with linked records, rule explanations, and next investigative steps.
5. Unrelated events stay separated; the analyst remains responsible for decisions.

The system is a local synthetic demonstration, not a deployed monitoring service.
